# ROHILA E-MITRA CENTER - New Version 1

## Upload
ZIP extract करें और सभी files GitHub repository के root में upload करें.

## Firebase
1. Firebase Authentication > Sign-in method में Email/Password enable करें.
2. Authentication > Users में अपना admin email/password बनाएँ.
3. Firestore और Storage rules के लिए firestore.rules और storage.rules की सामग्री Firebase Console में publish करें.

## जरूरी बदलाव
